LiteLLM이란?

통합 인터페이스

OpenAI, Anthropic, Vertex AI 등 100개 이상의 LLM을 하나의 completion() 호출로 사용. provider만 바꾸면 코드 수정 불필요.

AI Gateway

Self-hosted 프록시 서버로 팀 전체의 LLM 접근을 중앙 관리. Virtual Keys, 예산 제한, 로드 밸런싱을 오픈소스로 제공.

Python SDK

OpenAI SDK와 100% 호환. completion, embedding, streaming을 동일한 인터페이스로 호출하고, Observability 콜백으로 즉시 모니터링 가능.

프로덕션 레디

P95 레이턴시 8ms @ 1k RPS. Docker, Terraform, Helm Chart 등 검증된 배포 옵션. Stripe, Google ADK 등 대규모 기업 채택.

핵심 기능

Unified Interface

provider/model 형식으로 호출하면 SDK, 인증, 포맷 차이를 완전히 추상화. 코드 변경 없이 모델 전환 가능.

Routing & Failover

여러 배포 간 로드 밸런싱 + 장애 시 자동 fallback. Azure, OpenAI 등 크로스 배포 장애도 자동 복구.

Guardrails

콘텐츠 필터링, PII 마스킹, 안전성 검사를 요청/응답 파이프라인에 삽입. 커스텀 가드레일도 가능.

Cost Tracking

키별, 팀별, 사용자별 사용량과 비용을 실시간 추적. 예산 한도 초과 시 자동 차단 지원.

MCP & Agent Gateway

LLM 호출뿐 아니라 MCP 도구, A2A 에이전트까지 하나의 엔드포인트로 통합. 별도 게이트웨이 불필요.

Observability

Langfuse, MLflow, Helicone 등과 원 줄 콜백으로 즉시 연동. 커스텀 콜백으로 전 과정 모니터링 가능.

Quick Start

Python SDK

model 파라미터만 바꾸면 모든 제공사를 동일한 방식으로 호출합니다.

from litellm import completion # OpenAI response = completion( model="openai/gpt-4o", messages=[{"role": "user", "content": "안녕하세요!"}] ) # 제공사 전환 — 코드 변경 불필요 # model="anthropic/claude-3-5-sonnet" # model="vertex_ai/gemini-1.5-pro" # model="bedrock/anthropic.claude-haiku"

Proxy Server (AI Gateway)

프록시를 배포하면 OpenAI SDK를 그대로 사용할 수 있습니다.

# 프록시 시작 $ litellm --model openai/gpt-4o # → http://localhost:4000 # OpenAI SDK로 그대로 호출 import openai client = openai.OpenAI( api_key="anything", base_url="http://localhost:4000" ) response = client.chat.completions.create( model="gpt-4o", messages=[{"role": "user", "content": "Write a poem"}] )

에러 핸들링 & Observability

에러를 제공사에 맞춰 자동 변환

  • 모든 제공사 에러를 OpenAI 예외 타입으로 자동 매핑
  • AuthenticationError, RateLimitError 등 일관된 인터페이스
  • 제공사를 바꿔도 기존 에러 핸들링 코드 그대로 유지
  • Streaming, Function Calling 등 모든 시나리오에서 동작

전 과정을 한 줄로 추적

  • Langfuse, MLflow, Helicone 등 성숙한 관측 도구와 즉시 연동
  • 커스텀 콜백으로 요청/응답/비용/레이턴시 전부 수집
  • OpenTelemetry 기반 분산 추적 지원
  • 프로덕션 환경에서도 부담 없는 오버헤드

유연한 배포 방식

Docker

docker run 또는 docker-compose로 즉시 배포. 프로덕션 환경에서도 안정적으로 사용 가능합니다.

가장 간편한 시작

Terraform

AWS ECS Fargate, GCP Cloud Run용 프로덕션 모듈 제공. Managed Postgres + Redis 통합 구성.

인프라 자동화

Kubernetes

Helm Chart로 K8s 클러스터에 배포. Auto-scaling, 서비스 디스커버리, 로드 밸런싱 지원.

대규모 오케스트레이션

Managed Service

BerriAI에서 호스팅하는 완전 관리형 버전. 인프라 걱정 없이 바로 사용, 엔터프라이즈 SLA 적용.
